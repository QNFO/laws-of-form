# The Verb Lexicon

**Describing the Patterns We Mistake for People**

A dictionary of the missing verbs for fluid, relational human processes. Zero advice.

---

## About

English is a noun-heavy language. Because we lack the verbs to describe fluid, relational processes, we panic and invent nouns instead. *The Empath. The Overthinker. The Hero.* The noun sounds like a verdict. A life sentence.

The Verb Lexicon supplies 13 missing verbs — universal motions every human system moves through — described without judgment, diagnosis, or advice. It is a dictionary, not a manual.

This book draws a line from two companion works:
- **[Knowing Patterns: An Epistemology for People Tired of Being Fixed](https://rwnq8.github.io/knowing-patterns/)** — The epistemological foundation
- **The One Who Tells** — A personal essay applying the verbs to a single life

## Structure

| Part | Verbs |
|---|---|
| **I: Attention** — How the system looks at the world | Scanning, Locking, Drifting |
| **II: Friction** — How the system behaves when it hits a wall | Forcing, Spinning, Bracing |
| **III: Relation** — How the system interacts with other systems | Merging, Echoing, Tilting |
| **IV: Narrative** — The stories the system runs | Projecting, Fixing, Performing, Architecting |
